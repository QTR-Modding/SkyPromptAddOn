# SkyPrompt AddOn (Community Extensions)

Welcome to the (open‑source) SkyPrompt AddOn repository.  
Its purpose is to provide a shared, community‑maintained space where mod authors can contribute and distribute extra visual / interactive extensions for the [SkyPrompt](https://www.nexusmods.com/skyrimspecialedition/mods/148703) system.

At the moment, this AddOn focuses on [**Special Effects**](https://github.com/QTR-Modding/SkyPromptAddOn/wiki/Special-Effects) that themes can opt into.<br>
See [here](https://github.com/QTR-Modding/SkyPromptAPI/wiki/SkyPrompt-API-Tutorial-(cpp)#optional-requesting-a-theme) for more info on themes.
